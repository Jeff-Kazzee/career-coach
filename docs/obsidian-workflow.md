# Obsidian Workflow

Use this repo as the public method and your Obsidian vault as the private career cockpit.

## Recommended Vault Folder

```text
Career Coach/
  README.md
  Career Intake.md
  Career Scorecard.md
  30-Day Plan.md
  Proof Inventory.md
  Performance Evidence.md
  Weekly Logs/
  Applications/
  Interviews/
  Outreach/
  Research/
```

## Setup

1. Copy the templates you need from `assets/` into your private vault.
2. Fill out `Career Intake.md` with only the facts that are useful now.
3. Create or update `Career Scorecard.md`.
4. Pick one current mode: baseline, job search, resume/profile, interview, performance, career change, or freelance/indie.
5. Run a weekly review from the latest evidence, not from mood alone.

## The Weekly Loop

1. Capture what happened.
2. Separate actions from evidence.
3. Diagnose where progress stopped.
4. Choose one leverage point.
5. Set next week's commitments.
6. Keep the plan small enough to survive real life.

## What To Track

Actions:

- Applications sent
- Outreach messages
- Conversations
- Practice sessions
- Work shipped
- Feedback requests
- Portfolio or proof improvements

Evidence:

- Interviews earned
- Stronger resume bullets
- Manager/client feedback
- Expanded scope
- Useful market signal
- Paid experiments
- Offers or negotiation options

## What Not To Store In Public

Keep these in a private vault, never in a public repo:

- Resumes with contact details
- Employer or client confidential information
- Private salary notes
- Health, disability, benefit, immigration, tax, or legal details
- Job applications and recruiter messages
- Raw interview feedback tied to real people
- Private links

Never keep passwords, logins, access tokens, or account exports anywhere in the Career Coach folder. Use a password manager. An agent that reads the folder sends what it reads to the model provider.

## Agent Prompt Starter

```text
Use the career-coach skill. Read Career Intake.md, Career Scorecard.md, and the newest file in Weekly Logs/. Ask before opening anything else. Separate facts, assumptions, and missing information. Diagnose the current bottleneck, produce the useful artifact, and end with one bounded next action.
```

## Good Review Questions

1. What did I actually do this week?
2. What evidence changed?
3. Where did the funnel stop?
4. What am I avoiding?
5. What is the smallest action that creates new evidence?
